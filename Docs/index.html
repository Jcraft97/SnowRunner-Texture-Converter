SNOWRUNNER · EXPEDITIONS

ImageConverter

Command-line tools for converting game texture files to formats you can inspect and edit.

Texture converters

  • Expeditions DDS to SnowRunner TGADecode legacy DXT1 and DXT3 DDS textures.
  • SnowRunner TCIP PCT to TGADecode BC7 format IDs 51 and 52.
  • H2A Pict PCT to PNGDecode a separate PCT variant used for in-game images.

A .pct extension alone does not identify the file format. TCIP and H2A Pict PCT files require different converters.
