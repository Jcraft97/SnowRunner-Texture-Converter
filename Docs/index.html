ImageConverter

Command-line tools for converting texture formats used by SnowRunner and Expeditions.

Converters

  • Expeditions DDS to SnowRunner TGA — legacy DXT1/DXT3 DDS.
  • SnowRunner TCIP PCT to TGA — BC7 format IDs 51/52.
  • H2A Pict PCT to PNG — a separate PCT variant.

See the repository README for setup and usage. A .pct extension alone does not identify the PCT variant.
